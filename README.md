# 6º Projeto - Desafio - Análise-de-dados

Este projeto faz parte de um desafio proposto para a candidatura de uma vaga de Analista de Dados. 
A ideia é analisar os arquivos de dados de um banco fictício e responder as perguntas que o enunciado pede.
O arquivo com as perguntas se encontra no repositório do Github.

No contexto, a equipe do banco está receosa em se submeter a uma análise de dados pois acreditam que o modelo atual está funcionando bem. 
A ideia é o analista (no caso, eu) provar que é possível tirar novos insights, KPIs e informações valiosas da Análise de Dados e assim encontrar também gaps e conflitos aonde não estariam observando.  

Todo este projeto foi executado com **Python** e o dashboard feito com **Power BI**. Eis as atividades que serão realizadas:

* Uma análise exploratória dos arquivos para entender que tipo de informação tem nos dados.
* Levantar as principais métricas que da para retirar dos dados.
* Criação de uma dim_dates.
* Analise por dia de semana e por mês das transações.
* Adicionar a cotação do dolar a tabela de transações para calcular a correlação.

Foi utilizado as seguintes bibliotecasa e ferramentas:
* Python-Pandas - para manipulação, correção, e análise dos dados tabular
* Python-Seaborn, Matplotlib e Plottly para geração de gráficos
* Python-Numpy para operar cálculos matemáticos a fim de resolver situações
* Python-Datetime para trabalhar com dimensionamento de datas
* Power BI para construir o dashboard
